# internal-file-management
A secure way to share files between teams, friends and family members.

This project try to solve a problem that receivers and senders don't want 
to install or register any of the existing apps, but they still need to share 
files. 

There are some situations: 
1. A completely new computer needs some files.
2. A private files need to be shared 
3. Copy & Paste of one time data .
